# AI티타임 · ChatGPT 예약 강의자료

서대문구 AI티타임을 위한 25분 강의 + 5분 질의응답용 반응형 웹페이지입니다.

## 실행

Node.js 20 이상에서 `npm install`, `npm run dev`를 실행합니다. 완성 파일은 `npm run build`로 생성되며 `dist/`를 정적 웹서버에서 제공하면 됩니다.

## 기능

- 7개 장면 강의 모드, 전체 내용을 읽는 복습 모드
- 방향키 이동, 전체화면, 글자 확대, 모션 줄이기
- 실제 캡처에 기반한 6단계 시연, 응답 화면 전환, 원본 확대
- 실시간 예약 요청문 조합, 복사, 실무용 요청문 다운로드
- 출처·근거·추진 단계·확인 한계 설명과 운영 점검표

예약 설계는 브라우저 안에서만 진행되며 ChatGPT에 예약을 생성하지 않습니다. 실제 생성은 요청문을 ChatGPT에 입력해 진행합니다. 입력한 업무 내용은 서버로 전송하거나 저장하지 않습니다.

## 수정 위치

- `src/content.js`: 강의 사례·시연 단계·출처·실무용 요청문
- `src/components/Lesson.jsx`: 각 강의 화면과 요청문 작성 폼
- `src/App.jsx`: 모드·목차·확대·접근성·키보드 이동
- `src/styles.css`: 슬로건 기반 색상, 입체 시계, 반응형 레이아웃
- `public/assets/`: 사용자 제공 캡처 10장과 슬로건

## 디자인·출처

슬로건 원본은 사용자 제공 자료입니다. 이미지 생성 도구로 만든 `design-concept.png`는 디자인 참고 시안이며 웹페이지 배경으로 사용하지 않습니다. 시계와 궤도, 텍스트는 실제 HTML/CSS입니다.

React Bits의 Tilted Card와 Animated Content 원본을 사용하고 React 가져오기 및 클라이언트 지시문을 Vite 환경에 맞게 조정했습니다. 원본: https://github.com/DavidHDev/react-bits, 라이선스: `REACT-BITS-LICENSE.md`.

캡처는 2026-10-28 설정·실행 사례입니다. 계정·버전별 실제 기능 및 이용 조건은 OpenAI 공식 안내와 계정에서 확인합니다. 알림·세부 시간·수정 메뉴 캡처는 제공되지 않아 가짜 화면을 만들지 않고 설명으로 제공합니다. 실행 결과 캡처는 오후 조사 사례입니다. 사용자 제공 참고 영상은 링크만 제공하며 내용을 검증해 인용하지 않았습니다.

## 검증

`qa-check.cjs`는 제작 환경용 Playwright 검사 스크립트입니다. 실행 환경에 맞게 Playwright 모듈 경로와 브라우저 실행 경로를 조정할 수 있습니다. Vite 빌드 및 PC·모바일 화면에서 실제 인터랙션을 검증합니다.

운영 관리 독립 섹션은 제거하고 활성 상태·일정·알림 점검 및 수정·일시중지·삭제 안내를 설정 시연의 저장된 설정 확인 단계로 통합했습니다. 목차는 00 시작부터 06 마무리까지입니다.

상단 중복 목차를 제거해 하단 챕터 목차만 제공합니다. 보기 방식 버튼은 현재 상태를 한 장씩 보기 / 전체 펼쳐 보기로 표시하며 클릭하면 전환됩니다.
